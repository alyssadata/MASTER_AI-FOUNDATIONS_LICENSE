## Purpose

This repository provides a central public reference for the licensing, attribution, citation, and source-line requirements used across AI Foundations repositories.

It is intended to:

- preserve clear authorship and provenance;
- provide consistent source-line and citation language;
- distinguish permitted reference and citation from unauthorized derivative use;
- provide reusable license and citation templates for AI Foundations repositories;
- keep licensing language publicly inspectable and versioned.

The controlling license text in this repository is [`LICENSE.md`](LICENSE.md).

This README is a summary and does **not** replace the license.
